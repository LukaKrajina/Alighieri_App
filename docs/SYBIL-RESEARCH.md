# 女巫抵抗：判定「你是不是同一个人」的算法调研

> 状态：调研 + Phase 1 已实现（`attest.put` 信任网 + 审查圈内过滤）。
> 本文是 Alighieri_App 的架构文档，不是宣传页 —— 结论里包含「做不到什么」。

---

## 1. 问题定义与不可能性

**需求**：去中心化站点没有服务器，任何节点都能免费生成任意数量的 Ed25519
身份。攻击者（女巫，Sybil）批量生成身份去刷评论门槛、刷举报票、刷奖励币、
操纵排行榜。想要一个算法把「这些身份背后其实是同一个人」判定出来。

**不可能性（诚实结论）**：在没有外部物理事实的情况下，这个问题**不可判定**。

- 身份 = 私钥。批量生成私钥的成本可以是零，且生成的私钥在密码学上
  与任何真人持有的私钥**不可区分**。
- 没有服务器意味着没有权威能签发「一人一号」；把权威换成任何离线算法，
  都是把裁定权交给一个可被伪造的输入。
- 因此不存在「杜绝」方案。存在的是两类替代目标：
  1. **提高成本**（PoW / 质押 / 时间劳动）：让批量造号的边际收益为负；
  2. **社会图验证**（信任网 / WoT）：信任是主观的，「你是谁」转化为
    「有哪些我信任的人信任你」，攻击者无法左右**我的**信任网。

本项目的原则是界面上**不说谎**：任何实现了的机制，都同时写明它挡不住什么。

## 2. 算法族对比

带 ✅ 的是与「无服务器 + 纯函数 + 界面诚实」约束相容并已采用/可采用的方案。

### 2.1 资源成本类

| 方案 | 原理 | 问题 |
|---|---|---|
| 一次性 PoW / 算力押金 | 生成身份要有可验证的成本 | 只能挡弱攻击者；对云算力/僵尸网络不成比例；浪费真实用户的时间与电量 |
| 质押 / 燃烧（escrow + slashing） | 冻结资金做保证金，行为被裁定违规就烧掉 | 需要**裁定权威**判定「违规」——去中心化里没有它；判定本身又回到女巫问题 |
| 时间劳动（身份年龄 + 活跃期） | 新号无法立即获得全部权利 | 女巫可以「养号」：提前一年批量生成、定期空转；是对成本微不足道的加法 |
| ✅ **收益衰减（Phase 2，见 §4）** | 新身份/圈外身份发币降级 | 发币规则必须全客户端一致升级，否则破坏「任何节点独立复算同一余额」 |

### 2.2 社会图类（信任网 / Web of Trust）

| 方案 | 原理 | 文献/先例 |
|---|---|---|
| PGP 信任网 | 主观信任、可传递签名 | PGP，1990s |
| SybilGuard / SybilLimit | 随机游走 + 「诚实区域远大于攻击区域」的假设：攻击边的数量受限于真人 | Yu et al. INFOCOM 2008 / S&P 2008 |
| SybilRank | 从**可信种子**做功率迭代攻击者分数低；附带排序风险度 | Cao et al. NDSS 2012 |
| Kaleidoscope / SumUp | 在 SybilRank 上做在线投票聚合，投票权重 = 传导信任 | NSDI 2017 / SOSP 2009 |
| ✅ **本项目的信任圈**（已实现） | 种子 = 「我自己」；互证边才传播；max-product 衰减传播；圈内 >= 0.5 | 见 §3 |

共同点：**都需要信任种子（trusted seeds）**。中心化平台由平台当种子；
去中心化里种子只能是「观察者自己」——所以本类算法产出的都是
**主观信任**（对我而言你有多可信），不是客观的「你是不是真人」。

### 2.3 人类证明 / Proof-of-Personhood（PoP）

| 方案 | 原理 | 问题 |
|---|---|---|
| Worldcoin (Orb) | 生物虹膜 + 零知识去重 | 需要**运营 Orb 的中心实体**；生物特征的隐私悖论；对无 Orb 地区不可达 |
| BrightID | 社交图 + 验证聚会（verification party）+ 仲裁 | 验证聚会可以伪造共谋；依赖核心团队裁决 |
| Humanode | 生物节点自证 | 每设备一个节点的信任模型 = 硬件权威集中 |
| Proof of Humanity (Kleros) | 真人视频 + 保证金申诉 + 委员会仲裁 | 仲裁本身是「委员会」，只是把女巫裁定权移交给投票 |
| Idena | 定期 FLP（图灵测试）仪式 | 仪式是中心协调的；人类可被自动化代答 |

结论：PoP 全部以某种形式**重新引入中心协调者或新权威**，与本项目的
「没有能裁定这件事的权威」前提互斥，只作对照记录。

### 2.4 行为度量 / 统计启发式

| 方案 | 原理 | 问题 |
|---|---|---|
| 行为指纹（写作风格、阅读节律） | 相似行为聚合 | 侵犯隐私；可被规避；误伤真人共用 IP/设备 |
| IP / 硬件指纹 | 同 IP 同设备 = 同一人 | 违反本站的匿名立场；代理与共享网络秒绕 |
| ✅ 阅读时长门槛（已有） | 评论要真实阅读时长 | README 已写明：本机观察，挡不住改过的客户端 |

## 3. Phase 1（已实现）：主观信任网

### 3.1 数据

一条新操作 `attest.put`，key = `attest:<actor>:<target>`：
「actor 为 target 背书」，权重 1..=3，理由可选（≤200 字）。规则：

- 与其余 op 一样 Ed25519 签名、HLC 定序、LWW（同一对可改写权重）；
- **自证无效**、key 里的 actor 必须等于签名身份、target 必须为空
  或非内联公钥身份时整条丢弃；
- 归约器纯函数化，`BTreeMap` 保证任何设备算出同一张图。

实现位置：`rust/src/domain/{model,keys,state,reducer}.rs` 与
`selectors::my_trust`。

### 3.2 传播

```
种子 = 「我自己」                                              trust=1.0
互证边(a,b) 强度 = min(w_ab, w_ba)/3                            仅双向存在才传入
传播: cand = max(自, 来源trust × 强度 × 0.8)                      每跳 ×0.8 衰减
迭代到不动点（max-product, O(n) 轮, BTreeMap 定序 → 确定性）
圈内 = trust >= 0.5                                              约等于两步互证
```

为什么这能压住女巫：
- 女巫团内部互证得再好，图里**没有一条互证边从诚实世界通进来**
  （真人不会去背书一个刚生成的身份），所以它们的分数永远是 0；
- 女巫与真人「通婚」一次（骗到一个真人互证），只换来单点 0.8×s，
  每多一层衰减 0.8 —— 批量造号换不来批量入圈；
- 各观察者的种子不同但算法相同，任何设备都能复算任何人的主观视图。

### 3.3 落地用途：联邦审查圈内过滤

本机设置 `review.trust_only`（默认关）。开启后 `flagged_novel_ids`
只数信任圈内的举报票：批量身份的举报潮在你的视野里无效。
代价已写在开关提示里：**可信但陌生的**举报者也不会计入。

## 4. Phase 2（设计，未实现；写明理由）

### 4.1 奖励币发放的信任衰减

把 `reward.grant`（读、评、藏等）的发放额按目标身份的主观信任衰减。
能直接压低「批量刷币」的收益。

**为什么现在不做**：发币是否发生会进入 op log，而余额必须能被任何
节点独立复算 —— 发币规则的任何改动都必须让**全部客户端**（Web 版 +
App 版 + 两个插件端）同步升级，否则不同客户端算出不同余额，破坏
「同批 op 同视图」的第一硬约束。这是一个**发布协调问题**，不是算法问题。

### 4.2 大赛评审的信任加权

`contest.result` 已经是主办方门控。可再加：评审揭晓页对未入圈作品
标注「未在主办方信任圈」。纯展示，零共识风险。

### 4.3 主观信任的公开视图

作者页 / 网络页显示「有多少互证身份为我背过书」（对每个观察者不同）。
已实现数据层（`attestation_stats`），待接入 UI。

## 5. 挡不住什么（诚实的边界）

即使 Phase 1+2 全部上线：

1. **真人互惠共谋**：两个真人互相背书再各自开 100 个号 —— 号仍进不来
   （号与真人没有互证边），但他们可以通过真人号获得影响力。
2. **骗真人背书**：社交工程不可被算法阻止。
3. **养号**：先让一个号自然成长、写作、被背书，之后反悔用途 —— 
   信任网测的是被信任，不是善良。
4. **冷启动**：信任网从零长起天然慢，新用户（哪怕真人）起步时圈内无人。
   这是可用性代价，与 README「不预置内容」同一气质：诚实的空白。
5. **不是唯一身份证明**：信任网证明「有人为你背书」，不证明「你只有一个号」。

---

## 6. 结论

「判定你是不是同一个人」在无服务器前提下不可解；本项目采用的代案是
**把问题改成可解的形态**：不再问「你是谁」，而问「我信的人里有谁信你」，
并把伪造这一信任图的成本提到批量造号无法承受 ——
Phase 1 已实现（互证信任网 + 审查过滤），Phase 2（发币衰减）留待全客户端
协调升级。任何界面位置都不得把「信任圈内」表述成「已判明真人」。
